# Student Link

A web-based social platform for students.

This application is built using an HTML/CSS/JS software stack with a Firebase backend.

## Purpose

This application was built out of a collective frustration with the current state of campus communication methods.
We sought to make students communicating with their peers far easier.

In combination, we wanted to add more value than simple communication, so we implemented features such as social hubs, marketplaces, news, and events.
We aimed to create a feature-complete social media application that could compete with modern platforms and replace them as the main form of communication
between collaborating students.
